## QQ 反控查询

`!list`、`!tps` 等无破坏查询可以从 QQ 发起，并由机器人返回在线玩家和性能信息；高危操作仍受权限和确认流程约束。

![QQ RCON 查询](assets/qq-rcon-commands.png)
