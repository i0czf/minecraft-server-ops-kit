# 后台自动更新 · 玩家指南（新特性）

> 一句话：**你玩游戏的时候，管理员发的更新会在后台悄悄下好；下次重启游戏，直接就能用上新内容，不用再干等下载。**

---

## 你需要做什么？（几乎不用做什么）

- **老玩家**：照常用 **`更新mod-Windows端.bat`** 启动游戏就行。这个功能会自动就位，更新一两次后自动生效，**不用重新导入整合包**。
- **新玩家**：把管理员给的**最新规范导入包**导入 PCL/HMCL，然后用 **`更新mod-Windows端.bat`** 启动一次，之后就自动带这个功能了。

> ✅ 关键前提：**每次都用 `更新mod-Windows端.bat` 启动游戏**（它会先同步再拉起启动器）。
> 别直接双击 PCL/HMCL 启动——那样不会同步，也不会后台预下载。

---

## 它在游戏中是怎么工作的？

1. 你正在服务器里玩。
2. 管理员加了新模组、点了发布更新。
3. 🟡 **游戏聊天栏立刻弹出一条金色提示**：「[整合包更新] 服务器已发布新版本，你的客户端正在后台自动下载……」——这是**实时的、发布那一刻就到**。
4. **你的电脑在后台悄悄把新文件下载好**（通常几十秒内开始），全程不卡顿、不打断你游戏。
5. 下好后还会**明确提醒你**：
   - 🖥️ **Windows**：那个最小化的后台小黑窗会**自己弹出来、任务栏橙色闪烁**，并打出一条大字「整合包更新已就绪」——不抢你游戏焦点，你 alt-tab 或瞄一眼任务栏就能看到。
   - 🍎 **Mac**：右上角弹一条**系统通知**「整合包更新已就绪」（带提示音）。
   - 📄 两端都会在实例目录下写一个 **`更新已就绪.txt`**。

> 就算你当时在忙、没看到任何提示也**完全没关系**——下次重启游戏会自动应用，你不会漏掉任何更新。

---

## 怎么用上新内容？

**退出游戏 → 再次双击 `更新mod-Windows端.bat` → 秒进游戏，新内容已生效。**

- 因为下载在你上局游戏时就做完了，这次启动**不用再等下载**。
- 启动器窗口会显示类似「**已落位 X 个预下载文件**」「**同步完成**」，就代表新内容已经装好了。
- 你不需要单独去跑任何脚本，`更新mod-Windows端.bat` 就是你平时的启动方式。

---

## 几个要知道的点（避免踩坑）

- 🖥️ 启动后后台会多一个**最小化的小黑窗**（标题 `portable-stage-daemon`），那是后台下载器。**别手动关它**——你退出游戏后它会自己关闭。
- 🔒 更新**不会动**你的个人设置：键位、画质、存档、光影、资源包、你自己加的模型/枪皮，都会保留。你自己删掉的客户端模组也不会被同步装回来。
- 🍎 **Mac 玩家一样有这个功能**：照常用 `更新mod-Mac端.command` 启动即可；后台预下载 + 系统通知 + 重开生效，和 Windows 完全一致（需要装好 Java 和 python3）。

## 网络回退与老玩家兼容

- 更新器只自动使用公开更新地址，不再探测或访问局域网备用地址；这样外网玩家不会因局域网地址超时而等待。若管理员手动把主更新地址改成可达的内网地址，才会按手动配置使用。
- Windows 启动入口会先检查自刷新脚本和同步器的语法；如果包内保留了有效副本，可在启动前原子恢复损坏的 `_updater` 文件。
- 如果旧入口本身还能启动但完全无法访问它认识的更新地址，就无法凭空获得修复程序。此时应重新获取新版玩家包，或由管理员提供一个当前可达的更新地址。
- 管理员配置中的 `lanHost` 仍可用于管理员维护手动备用文件，但玩家更新器不会自动探测或读取它；不要把真实服务器配置文件提交到公版仓库。
- 更新器会记住上次成功的公开清单地址；已验证且大小、修改时间未变化的文件会跳过重复 SHA1，Python 路径还支持并行下载，官方源异常或低速时会更快回退到服端更新源。

## 常见问题

**Q：更新发布时游戏里有提示吗？**
A：有。发布那一刻，**游戏聊天栏会立刻弹一条金色的「[整合包更新]」提示**。下好后还会有桌面通知和 `更新已就绪.txt`。就算你全没注意到，**下次用 `更新mod-Windows端.bat` 重启游戏时会自动应用**，你什么都不会漏。

**Q：我必须一直开着那个小黑窗吗？**
A：不用管它。它会跟着你的游戏，你退出游戏它就自动收工了。

**Q：更新会不会把我的存档/键位弄丢？**
A：不会。这些都是受保护的个人文件，更新只换公共的模组和配置。

**Q：我一局游戏很久，中途发了好几次更新会怎样？**
A：都会被后台陆续下好，重启一次就全用上了。

**Q：后台下载失败了怎么办？**
A：没关系。就算后台没下成，下次启动时启动器也会照常把缺的补齐——后台只是帮你**提前**下好、省去等待，最终是否正确由启动时的同步兜底保证。

**Q：更新是从哪里下载的？会不会很慢？**
A：常见的公开模组会走 Modrinth 官方源，不经过管理员家里的宽带；汉化和本服私有文件才走服务器更新地址。你不用改任何操作，失败了会自动换源，下下来的文件都会校验。
