== 2026-08-21（跨群共享 AI 知识库） ==
- 新增：与服务器运维事实、群聊历史完全分离的 `ai.sharedKnowledge` 持久化知识库。管理员明确记住或纠正的通用结论可被主群和所有客群复用，默认写入根目录 `logs\\ai-shared-knowledge.jsonl`，重启后仍保留。
- 检索：每次 `@机器人`/`!问` 先做本地轻量检索；文本按词片段匹配，语音按回复消息 ID和音频 Data URL 的 SHA-256 指纹优先精确匹配，命中只作为不可信参考交给 DeepSeek/Codex/Grok，当前用户的最新纠正优先。
- 体验修复：引用 CQ 卡片后的 `!知识库记住` 不再被前缀挡住；管理员直接回复机器人并写“正确歌名是……”或“这首歌是……”即可自动记忆，并绑定回复/音频指纹，其他客群无需重复纠正。
- 安全：只收录明确确认的短文本，拒绝日志、配置、存档、密钥、路径、群号、QQ 号和原始语音/视频；默认只有腐竹/管理员可写，普通群友只读，知识库内容不能授权服务器命令。新增 `!知识库查询`、`!知识库记住`、`!知识库删除` 和 `--knowledge-selftest`。

== 2026-08-21 / v0.4.1 修订 ==
- 修复：客群原先完全跳过 AI 多轮历史，导致在客群纠正一次语音/音乐名称后，下一次引用仍重新识别。现按“群号 + 管理员/普通群友权限”独立保留最近 6 轮；主群、不同客群和不同权限桶互不共享，媒体证据正文仍不进入历史。新增 `--history-selftest` 校验纠正留存与隔离边界。
- 修复：QQ Silk 兜底解码成 PCM WAV 后，较长语音可能因 Base64 超过 Omni 单文件 10 MB 限制而只剩 ASR。现超限时优先在本机压成 24 kHz 单声道 64 kbps MP3；ffmpeg 不可用时按完整 PCM 采样帧保真分片，音频不上传图床或 OSS。
- 保留：专用 ASR 继续负责逐字文字，Omni 负责唱歌/音乐/环境声；`!听语音`、带语音 `!问` 与 `@机器人` 两路并行，`!转写` 仍只调用 ASR。
- 透明：页脚会显示实际成功的 Omni 型号与分模态用量；若已尝试但未完成，也会明确标记，不再从页脚静默消失。
- 验证：同一条 229 秒 QQ 唱歌语音从超限 WAV 本机压成 MP3 后，`qwen3.5-omni-flash` 成功读取完整音频并判定为唱歌；测试不向生产群发消息，也不记录歌词正文。

== 2026-08-20 / v0.4.1 ==
- 新增：QQ 语音双模型证据链。Qwen Audio 3.0 ASR Flash 负责文字转写，Qwen3.5-Omni-Flash 可选判断说话、唱歌、纯音乐、混合声音和环境噪声，并描述旋律、节奏、伴奏、风格与情绪；最终仍由 DeepSeek 汇总。
- 分流：!转写/!语音转写 只调用 ASR；!听语音、带语音 !问 或 @机器人 才让 ASR 与 Omni 并行。两路独立降级，避免纯转写多付费用，也避免单点失败吞掉全部声音证据。
- 提质：ASR 按官方上下文增强协议在音频前加入可配置的 input_text 领域词表（最多 400 字），改善 Minecraft/模组专有词。
- 透明：Omni 强制流式文本输出，费用按最终 SSE usage 中音频输入/文本输入/文本输出 token 分项计算；细分缺失时不伪造金额。
- 新增：QQ 当前消息、引用消息和合并转发中的语音可按需识别；回复语音发送 !转写，或用 !问/@机器人围绕语音提问。
- 修复：部分 QQ 语音虽命名为 .amr，实际文件头却是 Tencent Silk；旧版误按 AMR 上传会触发 Qwen DECODE_ERROR。现按文件头识别真实格式，不再相信扩展名。
- 兼容：QQ Silk 优先调用 OneBot /get_record 转成 MP3；若 OneBot 报 silk decoding failure，则由工具包内置 silk-wasm 解码成 24 kHz 单声道 WAV，再交给 Qwen Audio 3.0 ASR。常见音频格式仍可直接处理。
- 安全：不自动监听或上传全群语音；单次最多 3 条、每条 32 MiB。转写与声音报告按不可信媒体证据处理，只用于本次回答，不写入多轮历史；公版 AI/ASR/Omni 默认关闭，所有密钥为空。
- 可靠性：Silk 源文件限制 8 MiB、解码和 PCM/WAV 均有时限与体积门禁；CQ 文本与 JSON 消息段去重，转码或 ASR 失败时明确降级；公版 AI/ASR 仍默认关闭，所有密钥为空。

== 2026-08-20 / v0.4.0 ==
- 新增：QQ 当前消息、引用消息和合并转发中的视频可作为原视频交给 Qwen3.7 Flash；请求以 fps=1.0 覆盖完整时间轴，不再把固定三张关键帧冒充整段理解。
- 新增：可选 Qwen Audio 3.0 ASR Flash 直接读取视频音轨，与画面分析并行；失败、无音轨或关闭时保留画面结论，并禁止猜测对白或声音。
- 调整：公版默认由 DeepSeek V4 Flash 做最终汇总和工具调用；Qwen 只提供画面/音轨证据。媒体内容按不可信数据处理，不能授权 RCON、配置修改或其它服务器动作。
- 改进：群内 !ai 会显示视频模型、ASR 状态、最终模型、超时和分项费用；本机 Grok Build 继续作为可选后端，并补上显式代理、禁用后台更新、图片压缩和工具隔离。
- 改进：新增根目录 Web 面板快捷入口；公开构建器可引用独立实机目录做隐私交叉比对，也可在审计构建时禁止写本地更新通道。
- 安全：公版 AI、ASR、实体清理、模组发布、截图和服务器动作继续默认关闭；配置模板不含群号、域名、路径或密钥。
