== 2026-08-20 / v0.4.0 ==
- 新增：QQ 当前消息、引用消息和合并转发中的视频可作为原视频交给 Qwen3.7 Flash；请求以 fps=1.0 覆盖完整时间轴，不再把固定三张关键帧冒充整段理解。
- 新增：可选 Qwen Audio 3.0 ASR Flash 直接读取视频音轨，与画面分析并行；失败、无音轨或关闭时保留画面结论，并禁止猜测对白或声音。
- 调整：公版默认由 DeepSeek V4 Flash 做最终汇总和工具调用；Qwen 只提供画面/音轨证据。媒体内容按不可信数据处理，不能授权 RCON、配置修改或其它服务器动作。
- 改进：群内 !ai 会显示视频模型、ASR 状态、最终模型、超时和分项费用；本机 Grok Build 继续作为可选后端，并补上显式代理、禁用后台更新、图片压缩和工具隔离。
- 改进：新增根目录 Web 面板快捷入口；公开构建器可引用独立实机目录做隐私交叉比对，也可在审计构建时禁止写本地更新通道。
- 安全：公版 AI、ASR、实体清理、模组发布、截图和服务器动作继续默认关闭；配置模板不含群号、域名、路径或密钥。
